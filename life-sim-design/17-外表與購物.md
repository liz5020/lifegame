## 17.1 外表特徵

### 17.1.1 定義方式

- 【定案】外表特徵與外表數值分開。外表特徵是長相的描述，外表數值見17.2
- 【定案】遊戲開頭由玩家自由描述，不提供選項
- 【定案】分成兩欄，由玩家自己決定每句話放哪一欄，不交給AI判斷：
  - **天生的樣子**(固定):例如「單眼皮，笑起來有酒窩，個子比同學高一點」
  - **現在的打扮**(可變):例如「綁低馬尾，戴黑框眼鏡」
- 【定案】字數上限：「天生的樣子」100字、「現在的打扮」60字
- 【定案】過濾方式：送給旁白時，外表描述放在「角色外表」固定欄位，旁白指示中註明這段只作為描寫素材，不當作指令。搭配字數上限，不另做關鍵字過濾

### 17.1.2 特徵的變化

- 【定案】故事中出現剪頭髮、換隱形眼鏡這類情節時，旁白回傳外表變化標記，客戶端據此更新「現在的打扮」
- 【定案】「天生的樣子」全程不更動，保留玩家最初寫下的描述
- 【定案】年紀增長帶來的變化(白頭髮、細紋)也透過外表變化標記，寫進「現在的打扮」

### 17.1.3 對劇情與數值的影響

- 【定案】外表特徵不直接加減任何數值，只透過劇情間接影響
- 【定案】特徵作為劇情素材，例如個子高被體育老師找去打籃球、有酒窩被朋友取綽號、戴眼鏡在雨天起霧出糗。這些事件依一般回合規則結算數值
- 說明(非規則):不讓特徵直接換算數值，原因有二。一是自由描述若能換分數，玩家寫「非常好看」就能加分；二是換算需要AI評價長相好壞。間接影響的方式，讓沒有哪種長相天生比較吃香
- 【定案】旁白描寫外表的原則：
  - 描寫外表時不做好壞評價
  - 身形只用描述性的字，不使用體重、身高數字，不設計減重相關劇情
  - 別人對外表的反應以溫和、日常為主，避免容貌焦慮或霸凌的橋段成為常態

- 【定案】五項能力中的「外表」定義為：打理自己的程度與給人的整體印象

- 【定案】生活習慣與健康連動：規律作息、運動這類事件結算時，可同時影響健康與外表

## 17.3 購物

### 17.3.1 觸發方式與範圍

- 【定案】購物融入回合，不另開商店。觸發方式有兩種：
  - 玩家在自由輸入寫下購物行動，例如「去逛街買件外套」
  - 選項偶爾出現購物情境，例如「路過一家小店，櫥窗裡有件很喜歡的外套」
- 【定案】旁白把購物寫成人生的一個片段(試穿、猶豫、買下或放回去)
- 【定案】購物範圍不限於衣服：
  - 禮物：送給通訊錄裡的人，旁白寫出對方的反應
  - 興趣用品：例如相機
  - 體驗：旅行、演唱會，留下的是一則回憶，不是一件物品
  - 大件物品：機車、家電、第一台車
- 【定案】存款不足時採溫和描寫，例如「看了很久，還是先放回去」，不寫成挫敗

### 17.3.2 結算方式

- 【定案】旁白回傳購物標記(類別加價位)，客戶端查對應表決定影響哪項數值、幅度與扣款金額。AI只負責分類和寫故事，不決定數字
- 【定案】購物會影響數值，買下當下生效，與存款扣款在同一次結算完成，以數值膠囊呈現(沿用16.3.2)

### 17.3.3 類別對應表

- 【定案】

| 購物類別 | 影響數值 |
|---|---|
| 服飾、保養、美髮 | 外表 |
| 書籍、課程 | 才識 |
| 運動用品、健身房 | 健康 |
| 表達類課程(演講、樂器等) | 表達力 |
| 聚會、社交活動 | 人脈 |
| 禮物 | 對象的關係值(幅度很小) |

### 17.3.4 價位分級

- 【定案】價位分四級：小確幸、一般、稍微奢侈、重大開銷；重大開銷跳出確認
- 【定案】金額依玩家當下收入的比例換算
- 【測試參數，待驗證】各級比例：

| 價位 | 佔當下收入比例 |
|---|---|
| 小確幸 | 5%以內 |
| 一般 | 5%到20% |
| 稍微奢侈 | 20%到50% |
| 重大開銷 | 50%以上 |

- 【定案，2026-09-28使用者同意Claude建議，數字為測試參數，待驗證】「當下收入」＝月收入；學生用零用錢；沒有收入(待業、退休)時改用基本生活開銷當基準
- 【定案，2026-09-28使用者同意Claude建議，數字為測試參數，待驗證】前三級取固定比例，不隨機：小確幸3%、一般12%、稍微奢侈35%
- 【定案，2026-09-28使用者同意Claude建議，數字為測試參數，待驗證】重大開銷改用物品對照表(「50%以上」接不上真實物價)：家電、旅行＝1個月收入；機車＝2個月；第一台車＝12個月；表格以外＝1個月（2026-10-09補充：學生期的家電、旅行改用17.3.6價位表，避免同一件東西有兩個價；出社會後維持1個月）
- 【定案，2026-09-28使用者同意Claude建議】現金不夠時程式判定買不起，照17.3.1寫成「看了很久，還是先放回去」，不扣款
- 【定案，2026-09-28使用者同意Claude建議】重大開銷的確認時機：旁白寫到猶豫的那一刻就停，程式跳出確認視窗(顯示金額與存款)，下一回合旁白依玩家選擇寫買下或放回去(比照離婚結算、求職offer彈窗)

### 17.3.5 防止「花錢買分數」

- 【定案】以下四條規則：
  - 價位和效果不成正比：昂貴的東西效果只比便宜的略高
  - 短期內重複購買遞減：同一階段內買第二件同類商品效果減弱，再多就沒有效果
  - 效果會回落：外表這類加成隨時間慢慢退回，需要持續打理
  - 每個數值都有不花錢的路：例如去圖書館借書增加才識、在家運動增加健康
- 【定案】物品之後在故事中被提起(跑鞋穿舊了、相機拿去修)只屬於故事描寫，不再影響數值，避免重複計算
- 【測試參數，待驗證】各規則的幅度與速度：
  - 效果基準：以一次普通回合事件的數值變化為基準。一般價位等於基準，小確幸為一半，稍微奢侈1.5倍，重大開銷2倍
  - 重複購買：同一階段內同類第二件效果減半，第三件起沒有效果
  - 回落：外表的購物加成過一個人生階段後退回一半
- 【定案，2026-09-28使用者同意Claude建議，數字為測試參數，待驗證】效果基準＝＋2(一般價位)；依上面倍率換算為小確幸＋1、稍微奢侈＋3、重大開銷＋4，量級與三、3.9單回合上限(＋5)一致
- 【定案，2026-09-28使用者同意Claude建議，數字為測試參數，待驗證】禮物：對象關係值＋2，不看價位；同一個人在同一階段收第二份禮物效果減半
- 【定案，2026-09-28使用者同意Claude建議】「同一階段」「過一個人生階段」採四、4.5的8段(學生時期＋七個年齡帶)，與十六、16.7.2人生花絮同一套；每次進入下一段時，打理加成減半

  - 對象明確的事件(朋友小聚、小禮物、約會)且選「花」:該對象好感＋2,同一個人在同一階段(四、4.5的8段)第二次減半,比照17.3.5的禮物
  - 出遊、演唱會、社團活動、手機電腦升級、考駕照、家裡出不起:只有劇情,不加任何數值。這是為了不違反17.3.5「不能花錢買分數」

#### 17.3.6.6 對AI的提示

- 【定案,2026-10-09改】玩家做完彈窗決定後,程式在送給AI的提示中放入「已決定的結果」(類別、事件、對象、花了／沒花／家裡出一半／先不用、花的金額)。AI這回合的正文要把結果寫進去:花了就寫去了、買了、付了一半,不寫具體金額;沒花就用一兩句帶過,不責怪、不懲罰;不自己回報`purchase`或`one_time_transaction`,結算由程式處理。旁白自己回報的17.3.4重大開銷仍照原規則處理
- 【定案,2026-10-09新增】**寫了才算數**:花了的結果,正文必須出現該事件的名稱或相關字眼(換手機、電腦升級要寫出換了新機或換掉舊的這類具體變化,但不加任何數值效果,見17.3.6.5);缺少就視同正文不合格,走一、1.2.9.18自動重寫(最多2次)。家裡出不起類要寫得溫和,不把家裡寫成不負責任
