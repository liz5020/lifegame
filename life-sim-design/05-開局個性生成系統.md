# 五、開局個性生成系統

## 5.1 設計原則
1. **多元性優先於分類乾淨**:放棄「單一教養風格→單一性格標籤」的線性對照,改用多條獨立軸線交叉組合,避免每次開局都落入固定原型。
2. **暗示不宣告**:任何背景設定(家境、性格傾向)一律透過場景細節、行為動作、他人反應間接透露,禁止旁白直接點名(如「你缺乏安全感」)。
3. **底色不是宿命**:所有性格相關設定都可透過玩家長期選擇緩慢修正,不是寫死的終身標籤。
4. **弱相關,非因果鎖定**:各軸線之間允許統計上的傾向性(例如高壓教養下逃避型機率略高),但不互相決定,避免刻板印象與退回單一結果。

---


## 5.2 四條核心軸線


### 5.2.1 家境(資源軸)
- **性質**:完全獨立骰,只決定財富/人脈起點,不影響教養風格或依附風格
- **呈現時機**:不在開局當天講明,留到後續回合透過同學反應、物品細節(便當、書包、手機)自然滲出
- **設計理由**:避免「窮困家庭教養較差」的暗示,把資源多寡跟人格好壞徹底切割


### 5.2.2 教養風格(親子關係軸)
- **管轄範圍**:父母角色卡的說話語氣、親子好感度起點、之後親子互動場景的基調
- **四種類型**:威權高壓 / 民主開放 / 放任不管 / 情感疏忽
- **好感度起點**:
  - 威權高壓:35-55
  - 民主開放:60-80
  - 放任不管:45-65
  - 情感疏忽:25-45
- **呈現時機**:不急著在開局第一天出現,留到玩家第一次與父母互動(當天放學訊息或隔幾天)時透過語氣自然帶出


### 5.2.3 依附風格(全人格軸)
- **管轄範圍**:玩家在所有關係中(不只父母)的行為模式,是貫穿全程的敘事語氣濾鏡
- **四種原型**(對應依附理論):安全型 / 焦慮型 / 逃避型 / 混亂型
- **與教養風格的關係**:弱相關,非必然對應(例如高壓教養下混亂/逃避型機率略高,但安全型依然可能出現)
- **呈現機制**:**光譜位移**,非固定標籤
  - 玩家每次選擇,在背後對光譜位置做小幅調整(例如選擇「主動求助」而非「自己扛」,逃避傾向值小幅下降)
  - 單次選擇位移幅度極小,需長期同方向累積才會讓底色真正鬆動,避免「選一次就整個翻轉」的失真感
  - 不宣告數值變化,靠敘事側寫呈現(NPC的一句評語、玩家內心話出現的一絲遲疑),且側寫本身是稀疏、不定期的


### 5.2.4 同儕位置(社會軸)
- **管轄範圍**:玩家在同儕互動中的行為模式與社交生態位
- **五種類型**:核心人氣圈 / 邊緣觀察者 / 小圈子黏著者 / 獨行俠 / 照顧者型
- 【定案，2026-09-27使用者同意Claude建議，測試參數】照顧者型不是永久標籤:同儕位置數值偏離取得標籤當時超過20分就解除，之後依數值落在其他四類
- **呈現時機**:開局第一天(走進教室是最自然的呈現場景)
- **後續變化**:與依附風格用同一套光譜位移邏輯——長期選擇軌跡可讓同儕位置緩慢滑動(例如長期選擇脫離小圈子,會漸漸滑向獨行俠),不用重新擲骰

### 5.2.5 家長職業(八大類)
- 【定案】家長職業分八大類,每類自帶不同的敘事鉤子,之後也是玩家自己職涯選擇的參照框架(見三、3.4.3正職薪資):
  1. **自營/家庭事業類**【15%】(餐飲、傳統零售、小型工廠/家庭代工):家庭義務型打工情境的來源(見十四、14.2.3),牽動玩家對「要不要接家業」的長期伏筆
  2. **受雇專業/白領類**【30%】(一般上班族、醫護/教職、公務員):作息規律,社會期待值高低不同,醫護/教職可能帶來隱性高標準壓力
  3. **勞力/服務類**【25%】(工廠作業員/司機/建築工、服務業輪班):體力消耗大,健康數值的家庭示範效應,作息日夜顛倒
  4. **不穩定/待業類**【5%】(打零工/待業中、負債/生意失敗後轉職):可能觸發玩家自發性想幫忙分擔的打工動機,或呼應家庭斷裂關鍵事件
  5. **長期不在身邊類**【5%】(遠洋/外派/工地跑點):半個單親家庭的日常感,適合跟依附風格的逃避/焦慮軸對話
  6. **自由/創作類**【8%】(自由接案設計/寫作/攝影):收入不穩定但時間彈性,親子相處模式特殊(常在家但工作中不能打擾)
  7. **軍公教/警消類**【10%】(軍職/警察/消防員、一般公教):高風險職業帶來隱性擔憂感,紀律性教養風格出現機率略高但非必然;公教穩定但可能帶出「求穩vs追求自己想要的路」的價值觀拉扯
  8. **政治人物子女**【2%】(市長/立委/更高層級):天生與高家境、高人脈起點掛勾(唯一允許打破軸線獨立性的例外),同儕態度可能因此改變,建議做成隱藏設定(玩家知道,但劇情不主動點名父母身分,靠他人反應側面帶出,見十四、14.1.5)
- 【定案,2026-10-08使用者確認,機率為測試參數,待驗證】八類依上列機率加權抽(合計100%),取代原本各12.5%平均抽(平均抽會讓雙親家庭約23%有一方是政治人物,偏高)。每位家長各自獨立抽;不抽政治人物的情況(5.2.6離異不同住/失聯/已故的一方)排除政治人物後,其餘按比例重新放大

### 5.2.6 家庭結構(新增獨立軸線)
- 【定案】家庭結構決定開局角色卡有誰,與家長職業分開骰:
  - **雙親同住**(預設多數情況)
  - **單親——離異**:另一方可能仍在通訊錄裡(依監護/探視安排,好感度另外計算),也可能長期失聯
    - 【定案，2026-09-27使用者授權Claude全權判斷，可覆寫，測試參數】60%仍有聯絡:建角色卡，稱謂標「（不同住）」、不同住、自己骰教養風格與職業(不抽政治人物)、好感度依自己的風格區間再−10；40%長期失聯:~~不建卡~~【2026-09-29改依四、4.6.2(`04-角色卡與人生歷史系統.md`)】建角色卡,一開始就是「失聯」狀態。不同住的一方不影響依附/社交起點與5.5三餐資格，也不套用十三、13.6「另一位家長照顧負荷提升」(兩人早已分開)，但照常進入13.5父母健康狀態機
  - **單親——喪親**:另一方不生成角色卡,但可能在特定情境被提起(生日/忌日等時間點自然帶出回憶,不強制觸發)
    - 【2026-09-29改依四、4.6.2】已過世的家長改為建角色卡,一開始就是「已故」狀態(取代上一行「不生成角色卡」);在特定情境被提起的做法不變
  - **隔代教養**:祖父母取代父母角色卡位置,教養風格語氣需要專屬模板(見十四、14.1.5)。【定案,2026-09-23新增】祖父母卡套用十三、13.5.1父母健康狀態機(年齡追蹤/長照決策/過世/遺產),不另訂新規則
  - **其中一方服刑中**:該家長角色卡依然存在,但互動形式不同(書信/探視,而非日常訊息),好感度基礎值偏低但非必然疏離
- 【定案】家庭結構與關鍵事件池的整合邏輯:若家庭結構為離異/喪親/服刑,代表「家庭斷裂」這個關鍵事件類別已在開局前發生過,不再從五、5.3關鍵事件池重複抽取;若家庭結構為雙親同住,家庭斷裂仍保留在關鍵事件池的30%機率內,可能被抽中

## 5.3 關鍵事件(機率性疊加變因)

- **觸發機率**:30%機率有一次關鍵事件,70%平順成長,避免每個角色都過度戲劇化
- **性質**:對依附光譜或同儕位置起點做一次**較大幅度**的單次位移(相對日常選項的漸進累積,這是單一衝擊性事件)
- **事件類別草案**:
  | 事件 | 主要影響 |
  |---|---|
  | 家庭斷裂(離異/長期缺席/過世) | 依附光譜偏向逃避或混亂 |
  | 反覆遷徙(多次轉學) | 同儕位置起點偏向獨行俠/觀察者 |
  | 社交創傷(排擠/霸凌) | 依附光譜偏向焦慮或逃避,方向依同時骰到的教養風格而定 |
  | 早熟的責任(家中變故需提前扛責任) | 同儕位置起點偏向照顧者型,依附光譜略偏逃避 |
  | 意外的高光時刻(比賽/關鍵時刻的成功經驗) | 依附光譜偏向安全型(唯一正向事件類型) |
- **呈現時機**:不在開局攤牌,留到遊戲中段相關情境自然觸發時,以簡短插敘/回憶帶出一角,不解釋前因後果,由玩家自行拼湊

## 5.4 軸線互動總表(七步驟骰定順序)

- 【定案】七個變因的骰定有明確的依賴順序,避免骰出互相矛盾的組合:

| 步驟 | 軸線 | 骰定邏輯 |
|---|---|---|
| 1 | 家庭結構 | 最優先骰定,決定角色卡名單,同時預先決定「家庭斷裂」關鍵事件是否已發生(見五、5.2.6) |
| 2 | 家長職業 | 只套用在還在世/在場的家長身上;若骰到政治人物子女,直接鎖定家境為高值,跳過第3步獨立骰(唯一允許打破軸線獨立性的例外) |
| 3 | 家境 | 獨立骰,除非被第2步的政治人物子女鎖定 |
| 4 | 教養風格 | 套用在現存家長身上;隔代教養/服刑家長需專屬語氣模板(見十四、14.1.5),不套用原本四種教養風格 |
| 5 | 依附風格 | 受教養風格弱相關影響,若第1步已有家庭斷裂的預設位移,依附風格起點已被推過一次,非從中立點開始 |
| 6 | 同儕位置 | 完全獨立骰,不受前面任何步驟影響 |
| 7 | 關鍵事件 | 30%機率,事件池排除第1步已用過的「家庭斷裂」類別(若適用) |

- 【定案】這樣骰下來,每個開局角色的背景故事是一條有邏輯的因果鏈,而非七個互不相干的隨機標籤硬湊在一起

## 5.5 生活方式選擇(9/14新增,玩家開局自選,非骰定)

> 本節是新增的開局步驟,跟5.4的七步驟骰定順序分開處理——骰定的是先天底色,這裡選的是行為偏好,性質不同,不放進骰定流程。詳細的財務公式見三、3.4.10。2026-09-28起開局選完之後,可以隨時在數值面板的生活方式小卡調整(見5.5.5)。

### 5.5.1 花錢習慣
- 【定案，2026-09-28改版，測試參數，待驗證】完全自由選,不受任何家庭條件限制:精打細算/普通花費/隨性大方,對應「可支配的錢花掉幾成」3成/6成/9成(原「基本開銷佔零用錢比例40%/60%/80%」,公式見3.4.10);三個選項隨時可在生活方式小卡改

### 5.5.2 三餐解決方式——資格判定
- 【定案】「家裡包辦」這個選項是否出現在開局可選清單裡,需先檢查家庭條件資格:

| 條件 | 資格 |
|---|---|
| 雙親同住 + 教養風格非放任不管/情感疏忽 + 家長職業非長期不在身邊類 | 可選 |
| 隔代教養 | 可選(無條件) |
| 家長職業為長期不在身邊類(遠洋/外派/工地跑點) | 不可選 |
| 家庭結構為服刑中一方,另一方也不符合上述可選條件 | 不可選 |
| 單親喪親,該家長職業為長期不在身邊類 | 不可選 |
| 教養風格為放任不管/情感疏忽(不論家長職業) | 不可選 |
| 家長職業為自營/家庭事業類(餐飲/零售/家庭代工) | 預設不可選,除非教養風格是民主開放或威權高壓則例外可選 |
| 不符合以上任何「可選」條件 | 不可選 |

- 【定案】不符合資格時,開局三餐選項只顯示「自己打理」「外食為主」兩項,不顯示「家裡包辦」

### 5.5.3 解鎖時機
- 【定案】大學階段選擇外縣市/出國分支:自動解鎖全部三個選項,不論原本資格如何
- 【定案】本地學生:維持原本的限制,直到出社會後才解鎖
- 【定案】出社會後(23歲以後,有正職或穩定打工收入):不論是否仍住家裡,一律解鎖全部三個選項
- 【定案】解鎖後,玩家可以重新選擇三餐解決方式,不強制沿用開局的選擇
- 【定案，2026-09-28改版】解鎖時跳出的視窗觸發時機不變,但不再直接在視窗裡選:標題維持「生活圈變了，三餐怎麼安排？」,內文「現在可以自己決定三餐怎麼解決了」,按鈕「去調整」直接打開生活方式小卡(5.5.5)、「之後再說」關閉視窗
- 【定案，2026-09-28】尚未解鎖時,生活方式小卡上的「家裡包辦」反灰,附一句原因「家裡目前不方便幫忙準備」

### 5.5.4 效果
- 三餐解決方式的開銷倍率、事件觸發機率倍率、興趣系統伏筆,詳見三、3.4.10

### 5.5.4.1 三餐方式在故事裡看得到(2026-10-09 claude.ai網頁版定案)

**背景**(說明用,非規則):三餐方式目前只以提示送給AI(`worker/prompt.js`「三餐解決方式」那條,語氣是「適合帶出」),沒有頻率規則,AI常常略過;玩家選了外食為主,開銷多1.1倍,故事裡卻看不到。

- 【定案】程式每隔一段時間排定一次「三餐提示」:
  - 條件:`mealArrangement`已選(出社會後尚未解鎖的人不排);距離上次排定至少3個月(遊戲內時間,依`timeState`日期);從選定三餐方式的那一刻起算第一次
  - 不排的情況:考試日、人生結束、同一回合已有彈窗、放置代活期間
  - 學生期與出社會後都適用
- 【定案,測試參數】排定時隨機選一種方式(各一半):
  - **A.正文一句帶過**:提示旁白可以在正文裡用一句話自然帶到三餐,不另寫畫面
  - **B.放進選項**:提示旁白,本回合`choices`其中一個可以跟三餐有關。對應:外食為主→放學跟同學去吃點東西(算「通往其他人」的選項,符合一、1.2.7選項多樣化);自己打理→晚上自己煮點什麼(算「主角一個人做的事」);家裡包辦→晚餐時跟家人聊聊(通往家人)
- 【定案】兩種都是**建議,不是命令**:旁白覺得不合適可以略過。程式不偵測旁白有沒有寫,排定後就重新計時
- 【定案】玩家選了B的選項,當一般回應處理,不加特別數值,也沒有懲罰
- 【定案】沿用現有限制:不寫具體金額、不回報扣款(開銷由系統結算)。`meal_event_multipliers`與`lifestyle_changed_now`維持原規則
- 【技術判斷】實作:修改`worker/prompt.js`的三餐條目並加入排定提示(動到`worker/`,推送前先問使用者;改prompt後必須重新部署Worker)。排定時間要存進存檔,放進`SNAPSHOT_EXTRA_KEYS`。與一、1.2.16重心場景指令同類型(都是程式在提示裡放建議),不改1.2.16原文
